# Builder AI 🚀

Builder AI is a full-stack AI-powered website generation platform that enables users to create complete websites using natural language prompts.

Users simply describe their idea, and Builder AI automatically plans the project structure, generates files, builds the frontend, and provides an interactive workspace for reviewing and editing the generated code.

## ✨ Features

* 🤖 AI-powered website generation
* 📝 Generate websites from text prompts
* 🔐 User authentication and authorization
* 📁 Project management dashboard
* 📂 Interactive file explorer
* 💻 Live code editing experience
* 🚀 Website publishing support
* 🎨 Modern responsive UI
* ⚡ Real-time project generation status tracking

## 🖼️ Application Preview

Builder AI allows users to describe their website idea and instantly generate a complete project structure.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Koteswararao95/Builder_AI.git
cd Builder_AI
```

### Install Backend Dependencies

```bash
cd server
npm install
npm run dev
```

### Install Frontend Dependencies

```bash
cd client
npm install
npm run dev
```

## 🔑 Environment Variables

Create a `.env` file in the server folder:

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
OPENROUTER_API_KEY=your_openrouter_api_key
```
